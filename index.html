Konfigurasi Proyek Firebase Anda

Penting: Aturan Keamanan (Security Rules) Firestore

Pastikan pada tab Firestore Database > Rules di Firebase Console Anda, aturan baca & tulis diizinkan agar aplikasi dapat menyimpan data: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
